# SSSSSSuger.github.io

这是一个可以直接部署到 GitHub Pages 的个人主页。

## 发布方式

1. 推送代码到 `main` 分支。
2. 打开 GitHub 仓库的 `Settings`。
3. 进入 `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`，保存。

如果仓库名是 `SSSSSSuger.github.io`，发布后主页地址通常是：

```text
https://SSSSSSuger.github.io
```

## 后续可替换内容

- `index.html`：修改个人介绍、项目链接和联系方式。
- `styles.css`：修改配色、排版和响应式布局。
- `script.js`：目前只负责自动更新页脚年份。

页面没有构建步骤，不需要安装依赖。
